# Security policy

MyExpense handles personal information. How it protects that information, and how to deploy it safely, is in [docs/SECURITY.md](docs/SECURITY.md).

## Reporting a vulnerability

If you find a way to see or change someone else's data, or any other security problem:

- **Don't** open a public issue.
- Report it privately through this repository's **Security → Report a vulnerability** (private vulnerability reporting), or contact the maintainer, @thedoncode, directly.
- Stop using the affected part of the app until it's fixed.

Expect an acknowledgement within 2 business days. A fix goes to QA first, then production, with the advisory published once production is patched.

## Supported versions

Only the current production release (the `main` branch and its published app) gets security fixes.
